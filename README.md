# Sign Editor GUI (Command Support)

## Feature

Allow players to modify the sign style and commands in the GUI.

The **OP features** switch in the footer is the sign's own `allow_op_features` flag, the one vanilla
uses to decide whether a sign parses its text components and whether their click commands may run.
The editor reads it from the sign when a side is loaded, sends the switch's value back with the
update, and the server stores it, so it is a property of the sign rather than a setting of the
window. It turns itself on when you type a command or a raw component, and can be switched off again
by hand.
